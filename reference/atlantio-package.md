# atlantio: Read, Write and Manipulate Atlantis Model Inputs and Outputs

Facilitate data wrangling and ecosystem analysis with Atlantis model
inputs and outputs. Provides an S7 class 'Atlantis' that represents an
Atlantis model, functions to read and write Atlantis files, and methods
to extract diet tables, food webs and time series from a model.

## Options

- `atlantio.verbose`: `"verbose"` (the default) prints the informative
  messages of atlantio, any other value (e.g. `"quiet"`) silences them.
