# Helper function to quickly access example files.

Helper function to quickly access example files.

## Usage

``` r
atlantis_examples(...)
```

## Arguments

- ...:

  further arguments passed to `[system.file()]`

## Examples

``` r
atlantis_examples("inputs", "tiny.bgm")
#> [1] "/home/runner/work/_temp/Library/atlantio/examples/inputs/tiny.bgm"
```
